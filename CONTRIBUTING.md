# Contributing Guide

This project uses a **vouch system** to ensure that contributions come from people who understand the project and have been reviewed by a maintainer.

## How to contribute

1. **Open a Discussion** using the "Vouch Request" template
2. Explain what you'd like to contribute and why
3. Wait for a maintainer to review and approve your request (by commenting `!vouch`)
4. Once approved, you'll be added to the vouched contributors list
5. You can then open a Pull Request

## Pull Requests without vouch

PRs from non-vouched users are automatically closed with an explanation. This is intentional and not a bug.
